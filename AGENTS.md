## Release automation

`CHANGELOG.md` is generated by release-please. Never edit it manually or add changelog entries; leave changelog updates to release-please.

PRs are squash-merged, and a PR with more than one commit lands under its **PR title**, which release-please then reads. Every PR title must use Conventional Commits format (`feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`, and so on), in addition to each commit message. A title without a type prefix, such as "Add library tools", produces no release.
